# Flight Recon Board

격자형 비행계획 정찰 프로토타입입니다.

## Play locally

정적 파일만으로 동작합니다. 저장소 루트의 `index.html`을 열거나 간단한 정적 서버로 실행하면 됩니다.

## GitHub Pages

GitHub에서 다음 설정을 켜면 테스트 URL로 플레이할 수 있습니다.

1. Repository `Settings`로 이동
2. `Pages` 메뉴 선택
3. `Build and deployment`에서 `Deploy from a branch` 선택
4. Branch: `main`, Folder: `/root` 선택
5. 저장 후 1~3분 대기

예상 URL:

`https://mecagun9.github.io/flight-recon-board/`
